# O0 worklog: src/game/t_2DFB70.c (-O0 C library, 0x2DFB70-0x2E62C0)

Looks like a sound/audio command library (command queue written into a 16-bit word buffer, voice allocation tables, IOP/thread helpers).

## -O0 tricks verified
- `x & 0xFFFFFFFFL` (long constant) keeps an `li -1; and` that `& -1`/`~0` would fold away.
- `a[i]--` computes the lvalue address three times (matches `lui/addiu` repeated); `a[i] = a[i] - 1` only twice.
- Chain narrowing of an int global to a uchar field gives `lbu` straight from the int; so globals written with `sw` stay `int`.
- `a + (c + b)` operand order sometimes needed to keep the original load order of `(a + c) + b`.
- Struct-array lvalues with distinct relocation symbols (D_003EA100/104/108) are separate `struct {int unk0; int pad[2];}` arrays.
- A `for` loop whose init store follows a label (after another loop) gets an extra `nop` before the store; write `i = 0; while (i < n) { ...; i++; }` instead.
- `buf[g++ + h + 4] = x` : post-increment of a gp global shows as `addiu v0,gp,off; lw v1,0(v0)` ... `sw v1,0(v0)`.
- `p + (a + (4 + b)) * 2` : operand order of the sum matters.
- `if (a) {...return;} else {}` reproduces a dead jump after a nested return.
- if/else-if chain, not `switch`, for 3 compares; `while (1)` emits `b body; b exit`.
- K&R definition (`f(a) unsigned short a;`) makes callers pass promoted ints (`lh` of a `(short)` cast).
- Loop with `break` then `return 0` at the end: `b` to a shared epilogue label.
- A K&R definition is needed when an earlier `f();` declaration exists and the function takes shorts (E00C8, E4EF8).
- `x * 4096` not `x << 12` when the asm copies the value first (`daddu $3,$2,$0; sll`). Chained `if ((G = f()) == 0)` copies via `move $3,$2` only when G is unsigned/pointer.
- `a >= 2 || a < 0 { return } else if (...) { return }` for a dead `b` after the first return; `cond ? bit1 : bit2` gives `bnez ok; b fail`.
